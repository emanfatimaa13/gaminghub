# 🎮 Gaming Store

> A modern **Gaming Accessories E-Commerce Website** built with **PHP, MySQL, Bootstrap 5, JavaScript, HTML5, and CSS3**.  
> The project includes a complete shopping experience with user authentication, wishlist, cart, checkout, and a powerful admin dashboard.

## 🚀 Installation

### Requirements

- PHP 7.4+
- MySQL
- XAMPP / WAMP

### Setup

```bash
git clone https://github.com/emanfatimaa13/gaming-store.git
```

1. Copy the project into the `htdocs` folder.
2. Start Apache and MySQL from XAMPP.
3. Create a database in phpMyAdmin.
4. Import `database.sql`.
5. Update database credentials in `config/database.php`.
6. Open:

```
http://localhost/gaming-store
```
